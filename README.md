# Cape Town Hair Studio Demo

A premium black-and-white **hair salon website demo** created for **The Hair Studio / Sue Maistry**. This project is a static marketing website built to present a high-end editorial visual style for a local hairdresser while also supporting local SEO content, service-focused landing pages, and a polished proposal flow for prospective clients.[page:233]

## Overview

This repository contains a multi-page hair salon website demo designed for a service-based hairdresser in Cape Town. The site combines brand presentation, service information, blog content, contact functionality, location targeting, and a package/proposal page inside one cohesive static website structure.[page:233]

The project is intended to demonstrate how a boutique hair studio website can balance aesthetics, credibility, conversion, and search visibility in a lightweight front-end build suitable for freelance client work and small business deployment.[page:233]

## Running Locally

Because this is a static site, no build process is required.

To run locally:

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` directly in a browser, or use a lightweight local server.

Example with Python:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
